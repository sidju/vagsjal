# Hashtag Categories

#wiki #help

Hashtags let you organise pages without a fixed folder structure.

## How it works

Add `#category-name` anywhere in a page and it will:

1. Appear as a clickable link to that category
2. Add this page to that category's listing
3. Generate a category index page (if no page with that name exists)

## Example

This page uses `#wiki` and `#help`. Both are clickable and link to category index pages listing every page with that tag.

## Linking between pages

Pages can have multiple #tags, and a category page lists all pages linked to it. See [Markdown help](markdown.md) for how to create links between pages.
