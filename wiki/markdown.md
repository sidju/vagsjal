# Markdown Help

#wiki #help

This wiki uses standard [CommonMark](https://commonmark.org/) markdown.

## Links

Link to other wiki pages using standard markdown links:

- `[Index](index.md)` → [Index](/wiki/index/)
- `[Markdown help](markdown.md#links)` → [Markdown help](/wiki/markdown/#links)

## Hashtags

Use #hashtags to categorise pages. A page can have multiple tags:

```
#regler #husregler #världen
```

Tags automatically become links to a category page listing all pages with that tag. See [categories](categories.md) for more.

## Formatting

| Style | Syntax |
|---|---|
| Bold | `**text**` |
| Italic | `*text*` |
| Strikethrough | `~~text~~` |
| Code | `` `code` `` |
| Code block | ```` ``` ```` |
